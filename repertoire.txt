# Each line is "white <system>:" or "black <system>:" and then moves in
# standard notation. A line gives the engine a preference for its own side's
# moves in it - never the opponent's - as a bonus at the root, so a move the
# search judges worse by more than the bonus is still not played. Each game
# one system per side is drawn to be the one it aims for, and its positions
# get the full Repertoire bonus; the rest of the repertoire gets half, so a
# game that leaves that system stays in the repertoire where it can.
# Positions, not move orders, are matched, so transpositions count.
# harness/repgen.py checks every move and writes src/repertoire.mach.
