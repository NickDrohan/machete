# Status branch

This branch is not for merging. It carries machete's status reports while the
owner is away. A report is written whenever the owner asks the main Claude
session for one (by Remote Control from a phone): it checks everything that is
running (lichess bot, queues, GPU training, the Mac and Pi farm, the search
tune), fixes what it can, keeps the queues full, and commits a report here.

- `STATUS.md` is the latest report.
- `reports/YYYY-MM-DD/HHMM.md` keeps every report.
- Live match boards: https://machete-live-f3bdfe.fly.dev

Comments on the pull request that tracks this branch are read at each report.
